# Snake Deluxe

A classic Snake game with a twist — runs entirely in the browser, single file, no dependencies.

## How to play

1. Open `index.html` in any modern browser (or serve the folder with any static server).
2. Use the **arrow keys** or **WASD** to steer the snake. On mobile, swipe on the board.
3. Avoid hitting the walls or your own tail.

## What makes it Deluxe

- 🍎 **Food** — +1 point, snake speeds up as you eat
- ⭐ **Golden star** — appears randomly, worth +5, but vanishes after 7 seconds (watch the countdown ring)
- 🛡 **Shield power-up** — survive one crash (walls wrap you around instead of killing you)
- ⚡ **Slow-mo power-up** — slows the game down for 6 seconds when things get too fast
- 🔥 **Combo system** — eat again within 5 seconds to stack up to a x5 score multiplier
- 🔊 **Sound effects** — generated in-browser, toggle with `M`
- ✨ **Particles, floating score text, and screen shake** for extra juice

Your best score is saved locally in the browser.

## Controls

| Action | Keys |
| --- | --- |
| Move | Arrow keys / WASD |
| Pause / resume | Space or P |
| Restart | Enter (on game over) |
| Sound on/off | M |
| Mobile | Swipe in any direction |
